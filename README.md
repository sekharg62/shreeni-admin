# Shreeni Admin

Admin dashboard for the Shreeni saree storefront — manage products, orders, and customers.

## Stack

- **Vite** + **React 19** + **TypeScript**
- **Tailwind CSS v4**
- **React Router** for routing
- **Recharts** for charts
- **lucide-react** for icons

## Getting started

```bash
npm install
npm run dev
```

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run lint` — run the linter

## Structure

- `src/components/ui/` — reusable UI library (Button, Input, Dropdown, Modal, Table, Tabs, DatePicker, etc.)
- `src/components/charts/` — chart components (Line, Bar, Diverging Bar, Pie/Donut)
- `src/pages/` — routed pages (Login, Dashboard, Component Library)
- `src/hooks/`, `src/lib/` — shared hooks and helpers

Visit `/components` for the live component library.
